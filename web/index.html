How A* Search Works

A* evaluates each node with the evaluation function: f(n) = g(n) + h(n)

  • g(n): Exact road network distance traveled from start node.
  • h(n): Admissible heuristic straight-line distance to goal: sqrt((x2-x1)² + (y2-y1)²).
  • f(n): Lowest estimated total travel cost.

Why A* Instead of Dijkstra?

Dijkstra expands nodes in all directions uniformly (blind search). A* uses the heuristic h(n) to direct the search toward the destination bin, exploring significantly fewer states and running much faster in large cities.

Heuristic Admissibility

A heuristic is admissible if h(n) ≤ h*(n) (never overestimates actual travel distance). Straight-line Euclidean distance is always ≤ winding road distance, guaranteeing that A* finds the mathematically optimal shortest path.

Adjacency List Graph (Unit 2)

Stored as Map<String, List<Edge>>. Space complexity is O(V + E), compared to O(V²) for adjacency matrix, making it memory-efficient for sparse city road networks.

Binary Max-Heap Priority Queue

Complete binary tree stored sequentially in a 1D array:

  • Parent(i) = (i - 1) / 2
  • LeftChild(i) = 2i + 1, RightChild(i) = 2i + 2
  • extractMax(): O(log N) via Heapify-Down.
  • insert(): O(log N) via Heapify-Up.

Re-Prioritization with Regression

Static fill alone causes overflow during peak hours. By incorporating Python's predicted fill rate, the Max-Heap elevates fast-filling bins to the root before they overflow, achieving proactive dispatching.

Encapsulation & Domain Models

Bin and Truck encapsulate private state variables (current fuel, fill liters, capacity). Mutations occur strictly via public business methods like loadWaste() and computePriority().

Composition in FleetManager

The FleetManager class implements a "has-a" relationship, orchestrating collections of trucks and bins, tracking fleet-wide diesel consumption, and enforcing capacity limits.

Interface & Comparable

Bin implements Comparable<Bin>, allowing clean integration with Java's collections framework and custom Heap data structures based on priority score.

Ordinary Least Squares (OLS)

Fits the best straight line y = mx + c through historical hourly readings:

m = (NΣxy - ΣxΣy) / (NΣx² - (Σx)²)

The slope m represents the exact waste accumulation rate (% per hour).

Goodness of Fit (R² Score)

Measures how accurately the linear equation models real waste generation: R² = 1 - (SS_res / SS_tot). Values close to 1.0 confirm consistent fill trends.

Decoupled Data Bridge

Java exports sensor records to historical_fill_data.csv. Python performs numerical regression and exports predicted_fill_rates.json. This decouples the heavy analytics engine from real-time routing.

Step 1 & 2: Graph Setup & Data Export

Java (ADSA & OOPJ): Represents city intersections and waste bins as an Adjacency List Graph (O(V+E) space). Exports sensor time-series to data/historical_fill_data.csv.

Step 3: Linear Regression Forecasting

Python (OLS Engine): Computes the fill accumulation rate m = Δy / Δx for each bin using Ordinary Least Squares regression, outputting data/predicted_fill_rates.json.

Step 4: Dynamic Max-Heap Urgency Ranking

Java (ADSA Unit 2): Priority score = Current_Fill% + (Predicted_Rate × 6h). Rapidly filling bins jump to the root of the Binary Max-Heap in O(log N) time.

Step 5: AI A* Route Search

Java (AI): Evaluates f(n) = g(n) + h(n) to generate the shortest road path connecting prioritized bins, skipping low-fill bins and saving 39.5% diesel fuel.
